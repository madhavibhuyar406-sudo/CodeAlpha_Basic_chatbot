# CodeAlpha_Basic_chatbot

This Basic Chatbot is a command-line Python project built during a CodeAlpha coding internship to practice conditional logic, loops, functions, and interactive user input handling. It responds to common greetings, basic questions, and everyday conversational prompts using rule-based matching until the user exits the chat. To run the chatbot, clone or download the repository and execute `python chatbot.py` in your terminal.
